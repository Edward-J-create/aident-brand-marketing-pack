# Copy Module

Use this reference only when the selected scope includes copy.

## Choose copy assets

| Asset | Default specification |
|---|---|
| Canonical names | company, brand, product, and feature names |
| Taglines | 3–5 meaningfully different options, labeled current, proposed, or approved |
| Positioning | category, audience, problem, differentiated value, and proof |
| Micro description | 120–140 characters |
| Short description | 200–250 characters |
| Medium description | 350–500 characters |
| Overview | 600–900 characters |
| Long overview | 1,000–1,200 characters |
| Audience blurbs | one per selected priority audience |
| Feature highlights | 4–8 items when a full set is requested |
| Value propositions | 3–6 benefit-and-proof pairs |
| Use cases | actor, task, and result |
| How it works | 3–6 accurate steps |
| Calls to action | primary and secondary by funnel stage |
| FAQ or objections | only questions supported by available facts |

These are menu items, not a mandatory bundle. Honor user-supplied ranges and counts over defaults.

## Drafting sequence

1. Draft one source-of-truth positioning narrative from the evidence ledger.
2. Derive shorter versions from that narrative.
3. Measure locale-appropriate character counts, including spaces and punctuation unless the user specifies another convention.
4. Adapt selected channels by hook, proof density, rhythm, formatting, and CTA without changing the underlying product truth.
5. Mark every unapproved line as proposed.

## Channel menu

| Channel | Typical assets |
|---|---|
| Website | hero, section copy, proof block, CTA, metadata |
| Product directory or app store | short and long descriptions, feature bullets, support links |
| LinkedIn | company description, launch post, proof-led post |
| X or Threads | bio, launch post, short thread |
| Instagram or TikTok | bio, captions, on-screen hooks, carousel copy |
| YouTube | titles, descriptions, pinned comment, thumbnail copy |
| Email | subjects, preview text, announcement or nurture copy |
| Partner or creator | approved facts, talking points, disclosure needs, do and avoid list |
| Sales or partnerships | short introduction, pitch bullets, follow-up copy |

For creator copy, provide fillable templates unless the creator actually used the product or ran the described workflow. Do not fabricate first-person experience.

## Copy completion

Report asset IDs, character counts where constrained, status, claim dependencies, and intended reuse. A complete copy module contains exactly the requested assets, not every row in the menu.

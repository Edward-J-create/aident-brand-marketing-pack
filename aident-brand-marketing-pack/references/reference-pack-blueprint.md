# Reference Pack Blueprint

This blueprint retains only the **generic category structure and granularity** of a user-supplied marketing pack. The original document URL, brand-specific copy, media links, account details, and identifiers are intentionally omitted from the public Skill. Use this anonymized checklist for a default complete pack; do not reconstruct or request the private source document when running the Skill.

| Order | Document category | Required content / honest substitute |
|---|---|---|
| 1 | English Copy | Brand/product names; tagline; positioning; 120–140, 200–250, 350–500, 600–900, and 1,000–1,200 character descriptions when English is requested; audience-tailored blurbs; feature highlights; value propositions; popular use cases; how it works; integrations/availability if relevant. Include actual written text and measured counts. |
| 2 | Official Links and Social Channels | Official website/product/docs/blog/billing links as relevant and actual Facebook, X, LinkedIn, YouTube, Instagram, Threads, TikTok accounts if they exist. An absent channel is `Not created`, not a fabricated URL. |
| 3 | Brand Assets | Logo variants for light/dark backgrounds and lockups; avatars/profile imagery; email header; YouTube, LinkedIn, X and other requested banners; video cover; marketing visuals/ads; product and website screenshots. For each approved existing item, show the image in the document when supported **and retain the verified original file** in a durable companion library; missing media gets a specific mini-brief. |
| 4 | Launch Video | Verified original master/export and document poster/player when available; otherwise a labeled script + storyboard/shot-source brief with duration, format, cover, captions, and localization. A streaming page or playlist is reference only. |
| 5 | Video Clips Assets | Logo motion and feature/use-case clips or equivalent brand-relevant cutdowns, each with original file, status, format, and direct file location when available. |
| 6 | The Creative Rule | Concise operational voice, logo/media, claims, and accessibility rules. |
| 7 | Platform Template References | Fillable and sample formats for X/Threads, LinkedIn/YouTube descriptions, and the user's channels. |
| 8 | Workflow Ideas | Concrete ways to reuse the pack, with asset dependencies. |
| 9 | Accuracy Guardrails | What may be claimed, what must be verified, and what cannot be represented as already produced. |
| 10 | 中文 copy | Chinese brand/product names, tagline, positioning, descriptions, feature/value bullets, use cases, how it works, and integrations/availability when Chinese is requested. |
| 11 | 中文素材 | Chinese voiceover/subtitled video, cover, marketing visuals, product UI/website screenshots, and localized content recommendations when Chinese is requested. |

## Completeness and status rules

- Do not interpret the table as a requirement to create fictitious accounts or media. A document with actionable missing/concept records can be an **incomplete planning and copy draft**. A **ready-to-use asset pack** additionally requires every promised existing or produced media deliverable to have a verified, durable original file and rights appropriate to its labeled use.
- For source-led brands, preserve existing logo names, files, and rights. For idea-led brands, a logo *concept* is a brief with no fake preview; screenshots require a real product capture or are marked conceptual.
- The reference contains actual images and videos. When approved real media is accessible, collect the actual files rather than stopping at page, ZIP, playlist, or thumbnail links. If only public third-party material is visible, mark it reference-only until reuse rights and originals are secured. Never use a text brief as a visual stand-in without a status label.
- Add specialized categories when the brand demands them, but retain the core sequence. Brand-irrelevant integrations may be marked `Not applicable — reason` rather than invented.
- The long description rows are character-count targets, not permission to pad with repetitive copy. If there is too little verified information, use honest conceptual wording in idea-led mode or state the evidence gap in source-led mode.

## Acceptance test

Before delivery, compare headings in order, spot-check one complete copy row in each requested locale, and check every media family for an inspected original-file location or an explicit non-ready state. A preview or link to a source page is insufficient to claim delivered media. Ensure the first screen is a usable pack rather than an evidence ledger. Read back the cloud document and sample the companion originals to confirm conversion and access.
